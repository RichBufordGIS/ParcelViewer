Parcel Viewer

The main parcel workspace combines 2D and 3D review tools with selection, condo exploration, and parcel change request workflows.

Select multiple parcels at one time, including rectangle selection.
Paste parcel lists using comma, semicolon, or line-separated values for batch search.
Open condo buildings and floors in 3D and follow parcels through floor-level workflows.
Split is used for single-parcel requests. Combine is used when multiple parcels are selected.
Includes area and line measurement, basemap, layer list, home, zoom, compass, and 2D / 3D navigation tools.
View full Parcel Viewer details
  • Search can resolve parcel, condo, and address sources depending on the current Parcel Viewer context.
  • Condo search can move the user directly into 3D so building and floor tools line up with the selected result.
  • Selected parcels flow into the split / combine request logic, with single-parcel requests guarded from combine behavior.
  • The page includes dedicated map widgets for layer visibility, basemap changes, home, zoom, compass, and measurement.

Property Analysis

Property Analysis focuses on district review, selection workflows, and table-driven exploration of assessment-related layers.

Select multiple districts from the grouped district picker.
Review results in the feature table tied directly to the Property Analysis map.
Use the layer list to review and compare map content while working through district selections.
Shared search supports parcel, condo, and address lookups in the Property Analysis context.
View full Property Analysis details
  • The district combobox is organized into CID, TDD, TIF Projects, and TIF Plan District groups.
  • Selections feed into the map and feature table so users can inspect both geometry and records together.
  • The page is set up well for future deep-dive help content or animated demos of district filtering.

Public Works

Public Works is a focused tab for map access and search, with room to grow as more PW-specific tools are added.

Uses the shared search framework for parcel, condo, and address search sources.
Includes map tools such as basemap access in the Public Works view.
Visibility is tied to actual content access so only users with PW access should see this tab.
View full Public Works details
  • The Public Works tab uses the same shared header search controller as the rest of the app, keeping search behavior consistent.
  • The current PW page is intentionally lighter than Parcel Viewer and can absorb more tool-specific help as new widgets are added.
