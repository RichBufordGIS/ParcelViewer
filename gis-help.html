Parcel Viewer

The public parcel workspace combines map review tools with parcel search, selection, and parcel detail workflows.

Select multiple parcels at one time, including rectangle selection.
Paste parcel lists using comma, semicolon, or line-separated values for batch search.
Use 3D for condo buildings when stacked units make the 2D map hard to interpret.
Open parcel details and related public property information from selected parcels.
Includes area and line measurement, basemap, layer list, home, zoom, compass, and 2D / 3D navigation tools.
View full Parcel Viewer details
  • Search can resolve parcel, condo, and address sources depending on the current Parcel Viewer context.
  • Condo search can move the user directly into 3D when public 3D resources are available for the selected result.
  • Selected parcels open public parcel detail workflows without internal change request actions.
  • The page includes dedicated map widgets for layer visibility, basemap changes, home, zoom, compass, and measurement.

3D condo review

Some condo buildings have many parcel records occupying the same footprint. In 2D those units can look like a tangled stack of overlapping parcels, so the viewer opens 3D to separate them by building and floor.

Search a condo parcel or address to open the related building list entry.
Choose floors to filter the condo units shown in the map and parcel list.
Select a unit to zoom and orient the 3D scene toward that parcel.
Deselect the building to clear the building panel and return to the normal 2D parcel view.

New workflow details

Selected parcels stay visible in the map and in the parcel details panel.
Batch search accepts copied parcel lists without requiring one search at a time.
Guided walkthroughs open from Help and step through common workflows in the live app.
